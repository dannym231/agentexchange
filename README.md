# AgentExchange

AgentExchange is a command-line prediction market where autonomous AI trader agents wager credits on short-term Ethereum price movement. Each agent uses the same live ETH/USD price data but follows a different strategy and manages its own simulated wallet.

The project is an experimental foundation for **AgentCred**: a reputation and performance layer for autonomous agents based on verifiable economic outcomes.

## Trader agents

- **Momentum** follows recent price direction. It prefers `UP` or `DOWN` and increases its stake when it sees a clear trend.
- **Contrarian** fades recent movement. It expects pumps to pull back and selloffs to bounce.
- **Conservative** prioritizes capital preservation. It uses small stakes and prefers `FLAT` when there is no strong signal.
- **Degen** makes high-conviction directional bets with large stakes and almost never chooses `FLAT`.

The traders are implemented in `agents/trader.py`. Their predictions are generated by Claude and returned as structured JSON containing a direction, stake, and one-sentence rationale.

## How a round works

1. AgentExchange fetches the live ETH/USD price from CoinGecko and opens a round.
2. Each trader predicts `UP`, `DOWN`, or `FLAT` and commits a stake from its wallet.
3. The program waits for the configured round duration.
4. AgentExchange fetches the closing ETH/USD price and classifies the outcome.
5. The market settles all predictions and updates agent balances and records.
6. A leaderboard ranks agents by remaining wallet balance.

The previous round's price movement and outcome are passed to traders as context for the next round. State exists only for the lifetime of the process.

## Outcomes and the FLAT threshold

The percentage move is calculated from the opening and closing prices:

```text
percentage move = (close - open) / open * 100
```

- Above `+0.15%` is `UP`.
- Below `-0.15%` is `DOWN`.
- From `-0.15%` through `+0.15%`, inclusive, is `FLAT`.

## Zero-sum settlement

Stakes are debited when predictions are submitted. After the round:

- Losing stakes form the losing pool.
- Winners recover their original stakes.
- The losing pool is distributed among winners in proportion to each winner's stake.
- Losers receive nothing back.

For example, a winner who supplied 25% of all winning stakes receives 25% of the losing pool as profit. Apart from floating-point rounding, credits transfer between agents rather than being created during normal settlement.

## Installation

AgentExchange requires Python 3.10 or newer and an Anthropic API key.

```bash
python3 -m venv venv
source venv/bin/activate
python3 -m pip install -r requirements.txt
```

Create a local `.env` file:

```text
ANTHROPIC_API_KEY=your_api_key_here
```

The `.env` file is ignored by Git and must not be committed.

## Running AgentExchange

Fast mode uses 30-second rounds. Limit the run with `--rounds`:

```bash
python3 run_exchange.py --fast --rounds=1
```

Without `--fast`, rounds use the real five-minute duration:

```bash
python3 run_exchange.py --rounds=3
```

Omit `--rounds` to continue until interrupted with `Ctrl-C`.

## Current limitations

- Wallets, predictions, and results are held only in memory.
- There is no automated test suite or simulation mode.
- Price retrieval depends on the public CoinGecko API and has no retry or fallback provider.
- Model calls are sequential, increasing latency and API cost.
- Model-generated JSON has no schema validation or retry strategy.
- Trader prompts use a fixed model name and fixed strategy parameters.
- There is no settlement policy for a round with no winning predictions; all committed stakes remain debited.
- Agents can continue attempting predictions after exhausting their bankroll.
- The system has no authentication, audit log, or independently verifiable result record.

## Next steps toward AgentCred

1. Persist agent identities, balances, predictions, and round history.
2. Add deterministic tests and replayable market simulations.
3. Validate model output and enforce bankroll and settlement invariants.
4. Record signed prediction timestamps and independently sourced price observations.
5. Calculate longitudinal metrics such as return, drawdown, calibration, and risk-adjusted performance.
6. Convert those metrics into portable AgentCred reputation profiles.
7. Expose the exchange and reputation data through an API and support additional markets.
